01-Setup-Project
================

Purpose: Bootstrap SDD in a new or existing project with verified slash commands, terminal activation, docs, and governance baseline.
Read trigger: MUST read immediately before setting up or copying this framework into a project.
Applicability: SDD-Vibe (1-in-2 Single Workflow)

Prerequisites:
- Copy framework files to the **workspace/git root** (IDEs discover `.agents/` at the repo root, not nested subfolders).
- Read `AGENTS.md`, `docs/INDEX.md`, and `LICENSE.md`.
- **MANDATORY PRE-CODEBASE GATE:** Verify and activate custom slash commands in both the AI Chat dropdown (type `/` to see all 18 `*-ca-agent` commands) and Terminal CLI (`ls .agents/commands/*-ca-agent.md`) BEFORE creating any application directories.
- **COLLISION-FREE ACTIVATION:** After copying/renaming `SDD-Vibe-Framework/`, type **`activate ca agents`** (or `/activate-ca-agent`) in chat, OR run `.\activate-ca-agents.bat` (Windows) / `./activate-ca-agents` (macOS/Linux), OR run `python scripts/init_project.py --ides all` directly. (Uses `activate ca agents` instead of bare `activate`/`start`/`run` to avoid conflicts with Python `venv`, PowerShell `Start-Process`, and IDE built-ins.)
- **MANDATORY LOGS DIRECTORY:** Ensure `logs/` folder exists with `logs/.gitkeep` for development logs (`*.log`). Verify `logs/*.log` is ignored in `.gitignore`.
- **PRE-STEP 5 DOMAIN & SYSTEM DESIGN GATE:** Establish thorough domain knowledge and system design before issuing Prompt 1. If not manually prepared, ask the AI agent to explain and formulate system design during planning, and integrate it into Prompt 1.

Commands & Skills:
- Commands: `/activate-ca-agent`, `/team-ecosystem-ca-agent`, `/plan-ca-agent`, `/dashboard-ca-agent`, `/spec-check-ca-agent`
- Skills: Core repo skills (`agentic-team-ecosystem`, `requirements-analysis`, `prd-writer`, `task-planner`). Third-party GitHub/official skills (e.g. `anthropics/skills`, `grill-me`, `find-skill`, `serena`) are developer choice installed on-demand per `.agents/skills/agentic-team-ecosystem/references/07-curated-external-skills-registry.md`.

Procedure:
1. Custom Slash Commands & Terminal Activation (Step 0):
   - Open renamed project root in IDE.
   - Type `activate ca agents` (or `/activate-ca-agent`) in chat, OR run `.\activate-ca-agents.bat` / `./activate-ca-agents` (or `python scripts/init_project.py --ides all`) in terminal.
   - Type `/` in chat: confirm all 18 `*-ca-agent` commands appear with descriptions.
   - Run terminal check: confirm `.agents/commands/` files exist and are readable.
2. Define Product & Technical Governance Baseline:
   - Populate `docs/product.md`, `docs/prd.md` (including Section 5 Technical Requirements), `docs/system-architecture.md`, and `docs/tech-stacks.md`.
   - Maintain `LICENSE.md` and `.github/SECURITY.md`.
3. 5-Step Cyclic Prompt Loop Initialization:
   - Step 1: Reading Prompt (Ingest user intent, parameters, and constraints).
   - Step 2: Analysis Prompt & Plan (Deconstruct requirements before touching code).
   - Step 3: Check/Recheck `docs/` and `playbooks/`.
   - Step 4: Review `*.md` Guidelines.
   - Step 5: Overwrite Full Guidelines according to prompt requirements.
4. Verify Setup:
   - Run: `python scripts/check_docs.py` (if python is available) or verify docs manually.
   - Launch In-IDE Dashboard: `/dashboard-ca-agent` (runs dynamically across all monitor resolutions with current running task and HEAD commit pinned on top).

Required output:
- Active IDE slash commands in `/` dropdown, clean docs, and initialized `docs/product.md` + `docs/prd.md`.
- MUST stop at missing approval, unresolved policy conflict, or unsafe credentials.
